# 📧 AI Email Writer

An AI-powered Email Writer that generates professional, personalized emails instantly using Groq AI (Llama 3.1).

## 🚀 Live Demo

🔗 https://ai-email-writer-zonf.onrender.com

---

## ✨ Features

- 🤖 AI-powered email generation
- 👤 Personalized sender and recipient names
- 📝 Custom subject and purpose
- 🎯 Multiple writing tones
- 📋 Copy generated email
- 📄 Download email as PDF
- 🔄 Regenerate email instantly
- 📱 Responsive and modern UI

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- Groq API (Llama 3.1)
- Marked.js
- html2pdf.js

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/ananya11167/AI-Email-Writer.git
```

Go into the project folder

```bash
cd AI-Email-Writer
```

Install dependencies

```bash
npm install
```

Create a `.env` file

```env
GROQ_API_KEY=GROQ_API_KEY
```

Start the server

```bash
node server.js
```

Open

```
http://localhost:3000
```
